備份與還原 / Backup and restore

在設定中匯出加密備份，將檔案與備份還原金鑰分開妥善保管。 解除安裝前先確認備份可用；PDF 並非完整專案備份。開發者無法復原僅存於你裝置上的資料或遺失的備份還原金鑰。

Export an encrypted backup from Settings and keep the file and backup recovery key safely, separately. Check your backup before uninstalling. A PDF is not a complete project backup. The developer cannot recover device-only records or lost backup recovery keys.

權限 / Permissions

相機、照片、Face ID 與行事曆權限可在 iOS「設定」管理。拒絕權限會限制對應功能。

Manage camera, photos, Face ID and calendar access in iOS Settings. Denied permissions limit the related feature.
